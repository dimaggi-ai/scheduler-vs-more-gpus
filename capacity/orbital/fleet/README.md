# Capacity Orbital fleet survival sensitivity

This offline synthetic tool adds expected cohort survival and delayed replacement commissioning. It does not predict flight reliability from measurements, plan actual launches or control vehicles. Replacement cohorts and their delays are explicit inputs, never inferred from expected failures.

```sh
python3 -m capacity.orbital.fleet --request capacity/orbital/examples/fleet-evaluate.json
python3 -m capacity.orbital.fleet --request capacity/orbital/examples/fleet-compare.json --output /tmp/new-fleet-result.json
python3 -m unittest capacity.orbital.test_fleet -v
```

Agent entrypoint `fleet.api.dispatch(request)` takes exact `schema`, `id`, `tool`, `input` fields. Schema is `capacity-orbital/fleet-tool-v1`; tools are `evaluate`, `compare` and `economics`. Results explicitly deny execution/promotion. Stateless IDs are labels, not durable idempotency keys. Low-level pure functions `evaluate`, `compare`, `project_economics` raise validation exceptions; dispatch converts supported validation/IO errors to stable refusals. Requests are at most 1,000,000 bytes, 50,000 nodes, depth 32; up to 200 cohorts and 100 years. Outputs have at most 20,000 cohort-year rows. Existing parent modules are unchanged.

For cohort N, per-node capacity kW and hazard λ/year, expected survival at age t is N exp(-λt). Exact expected node-years on [a,b] are N exp(-λ(a-c)) × (-expm1(-λ(b-a)))/λ, with duration used for λ=0 and c the actual commission time. Actual commissioning is planned time plus declared delay. Age starts at actual commissioning; retirement is fixed, and a delay past retirement produces no commissioned capacity. Hazard is constant and independent per unit for expectation; correlated failures, radiation calibration, repairs, degradation and replacement queues are absent. Fractional expected counts are not integer observed vehicles.

Period intervals are [year-1, year); end snapshots are at year, with commissioning included and retirement excluded. Useful kW-years multiply exposure by supplied capacity, utilization and nonfailure availability. Annual periods are one year, so average useful kW has the same numeric value as useful kW-years. Failed, retired, surviving and uncommissioned expected counts conserve initial cohort count. A never-commissioned cohort remains uncommissioned, including after its scheduled retirement.

`annual_average_capacity_shortfall_kw` compares declared annual average useful demand with expected annual average output. It is **not** integrated unmet demand, an outage probability, mission deadline feasibility or an SLO. For example, 20 kW in the first half and zero in the second averages 10 kW but cannot continuously meet a 10 kW requirement. Cohort availability does not imply network/battery/thermal feasibility.

The no-delay comparison uses the same fixed retirement and hazard. Cumulative exposure cannot improve with longer delay at those fixed inputs, but a later year's capacity can increase because delayed units are younger. Signed annual delay-exposure deltas may therefore be negative. Hazard increases cannot improve exposure with other inputs fixed. `compare` permits only hazard/delay sensitivity changes, requires unchanged demand/count/capacity/utilization/availability/commissioning/retirement, and never updates or promotes the baseline. It is not evidence that a physically attainable improvement exists.

Economics projection requires the existing lifecycle template with empty cohorts and matching horizon. For each actual cohort-year interval it supplies original integer count/kW/utilization and mean survival × nonfailure availability to the existing calculator. This preserves annual integrated exposure and its existing year-end discount convention, not continuously discounted physics. Cashflow amounts/categories/times remain exactly caller-supplied: delays do not silently defer launch spending and expected failures do not generate replacement expenses. The existing 200-cohort limit applies to projected cohort-year rows; larger projections refuse while fleet evaluation may remain supported. Survival averaging is clamped to one only to avoid rounding above unity. No new economics engine, revenue model, currency conversion or financial advice is supplied.

All fixtures are authored synthetic assumptions under the repository licence. Source/input hashes bind repeatable calculations, not authenticity. Physical qualification, domain acceptance, calibrated hazards and real orbital operations remain separate gates. Tests use hand-computable exponential/zero-hazard cases, conservation, fixed-baseline comparisons, projection, malformed input and actual CLI refusal/recovery. Hosted matrix execution is pending delivery; local performance evidence is not an SLO.
